# وِردي – مراجعة وحفظ القرآن اليومية

تطبيق ويب (HTML واحد) يُحوَّل إلى تطبيق أندرويد APK عبر GitHub Actions باستخدام Capacitor.

## طريقة الاستخدام

1. أنشئ مستودعًا جديدًا على GitHub (اسمه مثلًا `wirdi`).
2. ارفع كل محتويات هذا المجلد إلى المستودع على الفرع `main`
   (من الموقع: Add file ← Upload files، واسحب الملفات والمجلدات كلها
   بما فيها المجلد المخفي `.github`).
3. افتح تبويب **Actions** وانتظر انتهاء «Build APK» (٥–١٠ دقائق تقريبًا).
   لو لم يبدأ تلقائيًا اضغط Run workflow.
4. نزّل الملف من:
   - تبويب **Releases** في المستودع (`app-debug.apk`)، أو
   - صفحة التشغيل ← Artifacts ← `wirdi-apk`.
5. انقل الـ APK إلى الهاتف وثبّته (فعّل «التثبيت من مصادر غير معروفة» عند الطلب).

## ملاحظات

- الملف الناتج نسخة debug موقّعة تلقائيًا، مناسبة للاستخدام الشخصي.
  للنشر على Google Play تحتاج نسخة release وتوقيعًا بمفتاحك الخاص.
- نص المصحف يُحمَّل من الإنترنت عند فتح التطبيق. لو لم يتوفر، استخدم الاستيراد
  اليدوي في تبويب «المصحف» (مرة واحدة).
- التطبيق نفسه في `www/index.html`، وأي تعديل عليه ثم رفعه يبني APK جديدًا.
